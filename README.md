# Python While Loop Practice

This repository contains my beginner-level Python practice using the `while` loop.

## Topics Covered

* Printing numbers from 1 to 10
* Printing even numbers
* Printing odd numbers
* Calculating the sum of numbers from 1 to 100
* Creating multiplication tables
* Taking user input
* Counting the number of digits in a number
* Using `%` (modulus) and `//` (integer division)

## Questions Practiced

### Q1. Print numbers from 1 to 10

Used a `while` loop to print numbers from 1 to 10.

### Q2. Print even numbers from 2 to 20

Used a `while` loop with an `if` condition to print even numbers.

### Q3. Print odd numbers from 1 to 20

Used the modulus operator `%` to identify odd numbers.

### Q4. Calculate the sum of numbers from 1 to 100

Used a `while` loop to continuously add numbers from 1 to 100.

### Q5. Multiplication Table

Created a multiplication table using a `while` loop and also practiced taking a number from the user.

### Q6. Count the Number of Digits

Used `while`, `% 10`, and `// 10` to count the number of digits in a number.
